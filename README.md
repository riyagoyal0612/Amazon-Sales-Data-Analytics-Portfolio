# 🛒 Amazon Sales Data Analytics Portfolio

## 📌 Project Overview

This project is an end-to-end **Amazon Sales Data Analytics** project designed to analyze sales performance, customer behavior, product performance, profitability, and order trends.

The project uses multiple data analytics tools — **Excel, SQL, Python, and Tableau** — to perform data analysis and create an interactive business dashboard.

The objective is to transform raw Amazon sales data into meaningful insights that can help understand sales trends, identify top-performing products and customers, analyze profitability, and support data-driven business decisions.

---

## 🎯 Project Objectives

- Analyze overall sales and profit performance
- Identify top-performing products
- Analyze sales by product category
- Identify top customers based on sales
- Analyze order status distribution
- Analyze payment methods
- Study yearly and monthly sales trends
- Calculate key business metrics
- Analyze customer and product performance
- Identify profitable and underperforming areas
- Create an interactive Tableau dashboard for business insights
